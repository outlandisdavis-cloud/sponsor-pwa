# Store Submission Checklist (Phase 6)

## Web PWA
- [ ] Lighthouse PWA score ≥ 90
- [ ] Offline works; installable
- [ ] Privacy policy linked

## Google Play (TWA)
- [ ] TWA wrapper built (Bubblewrap)
- [ ] Digital Asset Links verified
- [ ] Store listing, screenshots, content rating

## Apple App Store (Capacitor)
- [ ] Capacitor iOS project
- [ ] App Store review guidelines (medical/health claims careful)
- [ ] Privacy nutrition labels

## Final
- [ ] Security review
- [ ] Version bump + release notes
- [ ] Launch announcement
