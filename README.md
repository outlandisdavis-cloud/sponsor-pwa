# Sponsor

A privacy-first, offline-capable PWA for substance-use-disorder recovery support: on-device AI craving conversations, validated mood/relapse-risk tracking, and crisis escalation. All inference runs in the browser; user data never leaves the device.

See [`docs/SPONSOR_BUILD_PLAN.md`](docs/SPONSOR_BUILD_PLAN.md) for the full spec and 28-week roadmap.

**Status:** Phase 0 — spec reconstruction. No application code yet.

## Safety

This app is not a medical device. It never advises cold-turkey alcohol or benzodiazepine withdrawal (lethal risk) and always routes to licensed care and crisis lines (988, SAMHSA 1-800-662-HELP). PHQ-9 Item 9 triggers an uncloseable crisis modal.
